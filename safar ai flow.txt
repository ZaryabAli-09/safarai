SAFAR AI — TRIP GENERATION WORKFLOW
====================================

┌──────────────────────────────┐
│ 1. Collect trip requirements │
│ Destination, dates, budget,  │
│ interests, transport, travel │
│ style                        │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 2. Validate and sanitize     │
│ Validate inputs and enforce  │
│ the seven-day maximum        │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 3. Construct AI request      │
│ Trip details, budget, FX     │
│ exchange-rate rules, and the │
│ required JSON schema         │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 4. Generate itinerary        │
│ Primary: Groq GPT-OSS-120B   │
│ Fallback: Groq GPT-OSS-20B   │
│ Fallback: Groq Qwen          │
│ Final fallback: OpenRouter   │
│ Nemotron                     │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 5. Validate AI response      │
│ Parse JSON; normalize days,  │
│ dates, and IDs; reject       │
│ placeholders and errors      │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 6. Enrich itinerary          │
│ Geocode locations; add       │
│ images and weather data      │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 7. Reconcile budget          │
│ Align activities, flights,   │
│ and categories with the      │
│ specified budget             │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 8. Persist and present trip  │
│ Mark the trip as completed   │
│ and display the itinerary    │
└──────────────────────────────┘

Failure handling:
If validation fails or all AI providers are unavailable, set the trip
status to "draft" and display a retry notification.
