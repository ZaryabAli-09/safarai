SAFAR AI - TRIP GENERATION FLOW
===============================

┌──────────────────────────────┐
│ 1. User completes trip form  │
│ Destination, dates, budget,  │
│ interests, transport, style  │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 2. Validate and sanitize     │
│ Server checks input and      │
│ enforces maximum 7 days      │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 3. Build AI prompt           │
│ Trip details + budget/FX     │
│ rules + JSON response shape  │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 4. Generate itinerary        │
│ Groq GPT-OSS-120B            │
│        ↓ if unavailable      │
│ Groq GPT-OSS-20B             │
│        ↓ if unavailable      │
│ Groq Qwen                    │
│        ↓ if unavailable      │
│ OpenRouter Nemotron          │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 5. Parse and validate JSON   │
│ Normalize days, dates, IDs   │
│ Reject placeholders/errors   │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 6. Enrich itinerary          │
│ Geocode locations            │
│ Add images and weather       │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 7. Reconcile budget          │
│ Match activities, flights,   │
│ and categories to user budget│
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 8. Save and display trip     │
│ Save as completed and show   │
│ itinerary in the UI          │
└──────────────────────────────┘

If validation or all AI providers fail:
Trip status becomes "draft" and the user receives a retry message.
